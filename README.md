# Scientific Agent

Scientific Agent 是一个面向科研数据分析的智能执行平台。用户只需描述研究目标，系统就会根据可用的数据文件、数据库和模型能力，规划并执行分析任务，最后给出带证据的结果。

## 项目简介

项目聚焦于科研场景中的数据检索、指标计算、模型结果分析和训练覆盖检查，支持从任务理解到最终回答的完整执行链路。所有关键决策、工具调用、观察结果和错误都会保留在任务轨迹中，便于复核和问题定位。

## 核心能力

- CSV/Excel 数据分析、指标计算和结构分组比较。
- 实验、模型、预测和训练数据之间的关系查询。
- 受安全约束的 SQL 生成、范围校验和只读执行。
- 模型预测误差、训练覆盖和科学特征分析。
- 文件、数据库、模型与 MCP 能力的统一工具调用。
- 任务暂停、恢复、失败诊断和有界恢复。
- 面向用户的阶段化执行进度，以及可展开的开发者审计轨迹。

## 执行流程

一次任务通常经过五个阶段：

1. 任务理解：识别用户目标、范围和交付要求。
2. 规划：生成工具范围明确、完成条件清晰的执行步骤。
3. 数据分析：调用合适的数据、模型或计算工具。
4. 证据校验：检查结果是否满足范围、安全和证据要求。
5. 最终回答：汇总已验证结果，并说明未完成部分及其原因。

项目默认优先使用确定性逻辑；模型服务是可选能力。未配置模型时，仍可以使用本地示例数据和离线回放验证执行链路。

## 代码结构

- `app/`：后端 API、Agent runtime、工具和数据访问层。
- `web/`：Web 界面和任务执行轨迹展示。
- `skills/`：科研技能与工具契约。
- `evaluation/`：离线评测、回放和指标定义。
- `docs/`：架构、流程和工程记录。
- `tests/`：后端及协议测试。

## 安全原则

系统坚持只读分析、最小工具权限、数据范围校验和完整审计。真实密钥、缓存文件和历史运行产物不属于源代码提交内容。
